Mis Tareas es un Inbox personalizado donde cada usuario puede crear nuevos contenidos, recibir y ejecutar las tareas sobre los documentos, y publicarlos en la bblioteca.

Un documento se crea siempre con un circuito asociado llamado Proceso de Trabajo. El proceso de trabajo es una secuencia de tareas sobre el documento, -tales como Edición, Revisión, Aprobación,...-, hasta el último paso que es la Publicación en la Biblioteca.
La definición de cada circuito asociado a cada plantilla de contenidos es configurable por administradores en el Modelo de Información
Este panel muestra un avance con las tareas más recientes del inbox, en la consola de Mis Tareas se encuentran todas.
