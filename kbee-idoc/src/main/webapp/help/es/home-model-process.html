Cada Plantilla de Contenido puede tener procesos de trabajo asociados. Un proceso de trabajo es una secuencia de tareas que se ejecutan sobre un contenido (estrictamente un contenido es una instancia de la Plantilla de Contenidos). Estas tareas pueden ser de edición, revisión, aprobación, etcétera. Cada vez que se crea un nuevo contenido, o se cuando se edita una copia de trabajo desde la Biblioteca, se inicia un proceso de trabajo con sus tareas. Ver Sección Modelo de Información
