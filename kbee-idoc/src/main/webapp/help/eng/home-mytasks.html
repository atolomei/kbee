My Tasks is a personalized Inbox where each user can create new files, receive and execute tasks on them, and publish them in the libraries.

A file is always created with an associated circuit called business process.
A business process is a sequence of tasks on the file, -such as Edit, Review, Approval, ...-, until the last step, which is publication in the libraries.

The definition of each circuit associated with each template is configurable by administrators in the Information Model
