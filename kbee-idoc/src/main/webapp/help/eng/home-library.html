At the end of the editorial process ('publish' action in the Task form) the contents are sent to one or more Libraries.
Each library contains a subset of the published content.

In the KBEE Express version there are 3 libraries:
- Corporate contents of internal access of the organization,
- Customers. content accessible by internal users and clients -each client will see theirs-, and
- General. general content that any user can read.

VERSION CONTROL

The library contains the published version of a content,
In case a content is edited after being published, the library will show the new version until the edited version is published.

LIBRARY SETUP

The libraries are configurable by users with administrator profile.
